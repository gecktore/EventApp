# Event App

Кроссплатформенное мобильное приложение для поиска, создания и управления мероприятиями, разработанное на **Flutter**.

## ✨ Основные возможности

- 📅 **Лента событий** — просмотр актуальных мероприятий с фильтрацией по датам и категориям.
- ➕ **Создание мероприятий** — добавление собственных событий с описанием, временем и местом проведения.
- 🎟 **Регистрация и билеты** — быстрая запись на интересующие события в один клик.
- 🔔 **Уведомления** — напоминания о предстоящих мероприятиях.

## 🛠 Стек технологий

- **Фреймворк:** Flutter
- **Язык:** Dart
- **Платформы:** Android, iOS

## 🚀 Запуск проекта

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com
   cd event_app_3
   ```

2. **Установите зависимости:**
   ```bash
   flutter pub get
   ```

3. **Запустите приложение:**
   ```bash
   flutter run
   ```
